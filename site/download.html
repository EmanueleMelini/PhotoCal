Come si installa

  1. Tocca Scarica dal telefono Android e apri il file quando è scaricato.
  2. Se Android lo chiede, permetti al browser di installare app sconosciute.
  3. Tocca Installa. Gli aggiornamenti poi arrivano dall'app stessa.

Serve Android 8.0 o successivo. Per aggiornare scarica la nuova versione e installala sopra: i dati restano.

How to install it

  1. Tap Download on your Android phone and open the file once it's downloaded.
  2. If Android asks, allow the browser to install unknown apps.
  3. Tap Install. Updates then come from the app itself.

It needs Android 8.0 or later. To update, download the new version and install it over the old one: your data stay.
